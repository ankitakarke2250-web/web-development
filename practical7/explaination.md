# Practical 7: Apply Borders, Margins, and Padding to HTML Elements

## Aim
To apply borders, margins, and padding to HTML elements using an external CSS file.

## Explanation
This practical demonstrates how CSS is used to style HTML elements with different border styles, margins, and padding.

- **HTML File (`index.html`):** Contains the webpage structure, heading, and three content boxes.
- **External CSS (`style.css`):** Contains all styling rules and is connected to the HTML file using the `<link>` tag.
- **Solid Border:** The first box uses a 3px solid red border, 20px margin, and 15px padding.
- **Dashed Border:** The second box uses a 3px dashed green border, 30px margin, and 25px padding.
- **Dotted Border:** The third box uses a 4px dotted blue border, 15px margin, and 20px padding.
- **Background Color:** Different background colors are applied to each box.
- **Text Alignment:** The text is centered using `text-align: center`.

## CSS Properties Used

| Property | Purpose |
|---|---|
| `border` | Adds a border around an element |
| `margin` | Adds space outside an element |
| `padding` | Adds space inside an element |
| `background-color` | Sets the background color |
| `font-family` | Sets the font style |
| `text-align` | Aligns text |
| `border-style` | Defines solid, dashed, or dotted borders |

## How to Run
1. Create `index.html` and `style.css` in the same folder.
2. Link the CSS file using `<link rel="stylesheet" href="style.css">`.
3. Save both files.
4. Open `index.html` in a web browser.

## Result
Successfully applied different border styles, margins, and padding to HTML elements using an external CSS file.
