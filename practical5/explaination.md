# Practical 5: Apply Background Colors and Images to a Webpage

## Aim
To apply background colors and background images to a webpage using CSS.

## Explanation
This practical demonstrates how to use CSS to apply background colors and images to an HTML webpage.

- **Body:** Sets the webpage background color to light blue, uses Arial font, and centers the text.
- **Heading (`h1`):** Applies dark blue text, a light yellow background, and 15px padding.
- **Paragraph (`p`):** Applies white text, a dark green background, 18px font size, and 15px padding.
- **Image Section (`.image-section`):** Adds `bk.avif` as a background image using `background-image`.
- **Background Size:** The `cover` value makes the image cover the section.
- **Background Position:** The `center` value centers the image within the section.
- **Padding:** Adds space inside elements to improve their appearance.

## How to Add the Image
Place the `bk.avif` image in the same folder as the HTML file. Ensure the image filename and extension match the CSS path.

## Result
Successfully applied background colors and a background image to a webpage using CSS.
