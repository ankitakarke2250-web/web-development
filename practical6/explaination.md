# Practical 6: Style Text Using Font Properties

## Aim
To style text on a webpage using different CSS font properties.

## Explanation
This practical demonstrates how CSS font properties are used to change the appearance of text on an HTML webpage.

- **Font Family (`font-family`):** Specifies the font style, such as Arial, Times New Roman, or Verdana.
- **Font Size (`font-size`):** Changes the size of the text using units such as pixels (`px`).
- **Font Weight (`font-weight`):** Controls the thickness of text, such as normal or bold.
- **Font Style (`font-style`):** Displays text in normal, italic, or oblique style.
- **Text Decoration (`text-decoration`):** Adds or removes decorations such as underline.
- **Text Transform (`text-transform`):** Changes text to uppercase, lowercase, or capitalize each word.

## CSS Properties Used

| Property | Purpose |
|---|---|
| `font-family` | Changes the font type |
| `font-size` | Changes the text size |
| `font-weight` | Changes the thickness of text |
| `font-style` | Applies italic or normal styling |
| `text-decoration` | Adds or removes text decoration |
| `text-transform` | Changes the capitalization of text |

## Result
Successfully styled webpage text using different CSS font properties.
