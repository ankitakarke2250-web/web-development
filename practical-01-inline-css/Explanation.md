
# Practical 1: Create a Webpage Using Inline CSS

## Aim
To create a webpage using Inline CSS.

## Explanation
Inline CSS is used to apply styles directly to HTML elements using the `style` attribute.

## Technologies Used
- HTML
- CSS

## Implementation
1. Create a file named `practical1.html`.
2. Write the HTML code.
3. Apply CSS using the `style` attribute.
4. Save and open the file in a web browser.

## Example
```html
<h1 style="color: blue;">Welcome to My Webpage</h1>
<p style="font-size: 20px;">This is my first webpage.</p>
```

## Output
A webpage with a colored heading and styled paragraph is displayed.

## Result
Successfully created a webpage using Inline CSS.

## Learning Outcome
Learned how to apply styles directly to HTML elements using the `style` attribute.
