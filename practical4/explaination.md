# Practical 4: Style Headings and Paragraphs Using CSS

## Aim
To style HTML headings and paragraphs using CSS properties.

## Explanation
This practical demonstrates how CSS is used to improve the appearance of HTML headings and paragraphs.

- **Heading 1 (`h1`):** Sets the text color to blue, aligns the text to the center, and sets the font size to 36px.
- **Heading 2 (`h2`):** Sets the text color to green and uses the Arial font.
- **Paragraph (`p`):** Sets the text color to dark gray (`#333333`), font size to 18px, and font family to Arial.
- **Line Height:** The `line-height: 1.6` property improves spacing between lines.
- **Background Color:** The `background-color: lightyellow` property gives paragraphs a light-yellow background.
- **Padding:** The `padding: 10px` property adds space inside each paragraph.

## CSS Properties Used

| Property | Purpose |
|---|---|
| `color` | Changes text color |
| `text-align` | Aligns text |
| `font-size` | Changes text size |
| `font-family` | Sets the font style |
| `line-height` | Controls spacing between lines |
| `background-color` | Sets the background color |
| `padding` | Adds internal spacing |

## Result
Successfully styled HTML headings and paragraphs using CSS properties such as color, font size, text alignment, font family, line height, background color, and padding.
