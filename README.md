## Suggested Folder Structure

Save each practical in a separate folder as you complete it.

```text

├── README.md

│   └── index.html
├── practical-02-internal-css/

```

## How to Run a Practical

1. Open the practical folder in VS Code.
2. Open `index.html` in your web browser.
3. Edit the HTML or CSS code.
4. Refresh the browser to see your changes.
