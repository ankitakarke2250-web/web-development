
# Practical 2: Apply Internal CSS to an HTML Document

## Aim
To apply Internal CSS to an HTML document.

## Explanation
Internal CSS is used to style an HTML webpage by writing CSS rules inside the `<style>` tag in the `<head>` section of the HTML document.

It allows us to change the background color, text color, font size, alignment, and other styles of HTML elements.

## Technologies Used
- HTML5
- CSS3

## Implementation
1. Create a file named `index.html`.
2. Write the basic HTML structure.
3. Add the `<style>` tag inside the `<head>` section.
4. Write CSS rules inside the `<style>` tag.
5. Save the file and open it in a web browser.

## Example
```html
<style>
    h1 {
        color: blue;
        font-size: 36px;
    }

    p {
        color: green;
        font-size: 20px;
    }
</style>
```

## Output
A webpage with a colored heading, styled paragraphs, a background color, and a button is displayed.

## Result
Successfully applied Internal CSS to an HTML document.

## Learning Outcome
Learned how to style an HTML webpage using Internal CSS.
